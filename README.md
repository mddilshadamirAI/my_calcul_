# 🔄 P2P TRADING TOOL

One of the major features of the platform is the dedicated **P2P Trading Calculator**.

It allows multiple USDT transactions to be tracked in a single calculation.

### 🟢 Buy Transactions

Each buy can contain:

- USDT quantity
- ₹ / USDT rate
- Fee percentage

### 🔴 Sell Transactions

Each sell can contain:

- USDT quantity
- ₹ / USDT rate
- Fee percentage

### 📊 P2P Analytics

The calculator can determine:

- Total USDT purchased
- Total USDT sold
- Remaining USDT
- Total INR invested
- Total INR received
- Weighted average buy rate
- Weighted average sell rate
- Gross P2P profit
- Total fees
- Net P2P profit
- ROI

It also includes a **Quick P2P Calculator** for individual transactions.
